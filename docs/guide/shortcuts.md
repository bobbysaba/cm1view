# Mouse and keyboard

## Everywhere

| Do | Result |
|---|---|
| Drag the time slider; **⏮ ⏭** | Jump, or step one output. |
| **▶** and the speed list | Play through the outputs at 0.5×, 1×, 2× or 4×. |
| Click a series plot | Go to that time. |
| Click the lit tool again | Switch the tool off. |

## The map

| Do | Result |
|---|---|
| Drag | Pan. |
| Wheel | Zoom about the pointer; the map re-renders at full resolution. |
| Box zoom, reset, save (toolbar) | Zoom to a box; go back; save a PNG. |
| Hover | Position and value of the fill; time and value on a track fix. |
| ↑ ↓ or the wheel over a level box | Step through heights (0.25 km) or model levels. |

## Tools

| Tool | Do | Result |
|---|---|---|
| Sounding | Click | A sounding at the point. |
| Sounding | <kbd>Shift</kbd>-click | Add a point (up to four in all). |
| Sounding | Drag a box | The sounding averaged over the box. |
| Sounding | <kbd>Shift</kbd>-drag | Add a box. |
| Section | Click A, then B | Draw the section; a third click starts a new one. |
| Track (auto) | Click a storm | Track it; click near the track at another time to correct it. |
| Track (by hand) | Click | Set the fix at the shown time (and step on). |
| 3D box | Drag | Choose the region and open the 3D workspace. |
| 3D box → Seed box | Drag | Seeds for the 3D streamlines, inside the region. |

## Soundings (expanded view)

| Do | Result |
|---|---|
| Drag a box | Zoom that panel. |
| Drag (after a zoom) | Pan. <kbd>Shift</kbd>-drag does the other mode; ✥ / ⬚ switches. |
| **−** | Widen the view by 60%. |
| Double-click, **⟲** | Back to the full view. |
| **⤓** | Save the image as SVG. |
| Hover | Values read off the graphic. |

## Sections

| Do | Result |
|---|---|
| Drag | Box zoom (the default tool). |
| Wheel, pan, reset (toolbar) | As on the map; zoom stays inside the section. |

## 3D

| Do | Result |
|---|---|
| Drag | Rotate (or what *Mouse drag* is set to). |
| Right-drag | Move. |
| Wheel | Zoom. |
| Double-click | Reset the view. |
| Click a streamline | Select it (and plot a field along it). |
| Pointer along the card's plot | Marks that distance on each line in the scene. |
| Card: wheel, drag, ⤢ | Zoom, pan, enlarge. |

## Figure workspace

| Do | Result |
|---|---|
| ↶ ↷ | Undo and redo any change. |
| *Click …* list, then click the preview | Place an annotation, a section's A and B, or a point on a skew-T. |
| Drag between two points | Place a two-point item (arrow, line, box). |
| *Drag: move an annotation* | Move one by its text, marker, centre or end. |
| *Drag a box: plan-view area* | Set the area the plan views show. |
| **Actual size** | See the figure as large as it prints. |
